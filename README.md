## ✨ 功能特性

- **📍 时间轴导航** — 页面右侧显示对话时间轴，点击圆点即可跳转至任意消息
- **⭐ 消息收藏** — 长按圆点可收藏重要消息，收藏状态本地持久化保存
- **🌗 自动适配主题** — 自动跟随各平台的亮色 / 暗色模式
- **⚙️ 独立开关** — 可在弹窗中为每个平台单独开启或关闭
- **🌍 广泛支持** — 覆盖国内外主流 AI 对话平台

## 🧩 安装方式

### 方式一：Chrome 应用商店（推荐）

> 审核通过后上线，届时在此更新链接

### 方式二：手动加载开发版

1. 下载本仓库（点击右上角 Code → Download ZIP）
2. 解压，找到 `extension/` 文件夹
3. 浏览器地址栏输入 `chrome://extensions/`
4. 右上角开启「开发者模式」
5. 点击「加载已解压的扩展程序」，选择 `extension/` 文件夹

> Edge 用户同样适用，操作步骤完全一致

## ChatNav — AI Conversation Timeline

Adds an interactive timeline to AI chat pages so you can jump to any message instantly.

**Supported platforms:** ChatGPT · DeepSeek · Gemini · Kimi · Doubao · Tongyi · Yuanbao · Yiyan · Grok

**Features:**
- Click any dot on the timeline to jump to that message
- Long-press a dot to star/bookmark important messages
- Auto dark/light theme detection per platform
- Per-site enable/disable toggle in the popup

**Install:** Load the `extension/` folder as an unpacked extension in Chrome or Edge developer mode.
